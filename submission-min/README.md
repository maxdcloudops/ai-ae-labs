ДЗ 1 — це вже майже голий шаблон. Але це в 12 разів менше за розширену версію.)

## Що саме не потрапило сюди — і чим це коштує

| Пропущено | Бали |
|---|---|
| Конкурентний бенчмарк, retry/backoff, fault injection | до −20 (це `++ Advanced`, понад базові 80) |
| Звірка вартості з access-log гейтвея | ↑ те саме |
| CI-скан усієї історії gitleaks | ↑ те саме |
| Тести | у критеріях не оцінюються |
| Графіки | у критеріях не вимагаються |

**Окремо, і це вже не про Advanced:** без ключа провайдера базовий шлях **не
може продемонструвати відмову поза доменом** (ДЗ 1, критерій на 15 балів) і
**не може показати три діалоги з tool-call-ами** (ДЗ 2, частина з 15 балів).
Причина в обох випадках одна: базовий шлях покладається на те, що модель
послухається інструкції, а локальний mock-бекенд її ігнорує. У README кожного
ДЗ це написано прямо, разом із командами, які дають ці діалоги за наявності ключа.

## Розширена версія

[`submission/`](../submission/) — те саме плюс `++ Advanced`: доменна межа в коді
(відмова коштує 0 токенів і покрита тестом), конкурентний харнес, 11 сценаріїв
fault injection, звірка вартості двома незалежними обчислювачами, CI-скан
історії, 58 тестів і графіки.

Здавати варто **одну** з двох. Ця — мінімально достатня; та — на повні 100.
